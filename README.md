# ניתוח נתוני כדורגל

כלי פייתון קטן לניתוח בסיסי של סטטיסטיקות כדורגל מתוך קובץ CSV, כולל הדפסת סיכומים וגרף שערים לפי קבוצה.

## דרישות

- Python 3
- pandas
- matplotlib

התקנה:

```bash
pip install pandas matplotlib
```

## מבנה הפרויקט

- `dashboard.py` — מכיל את הפונקציה `analyze_football_data(file_path)` שמבצעת את הניתוח.

## מבנה קובץ הנתונים

קובץ ה-CSV צריך להכיל את העמודות הבאות:

| עמודה | תיאור |
| --- | --- |
| `Team` | שם הקבוצה |
| `Goals` | מספר שערים |
| `Assists` | מספר בישולים |
| `Yellow_Cards` | מספר כרטיסים צהובים |

דוגמה:

```csv
Team,Goals,Assists,Yellow_Cards
Maccabi,2,1,0
Hapoel,1,1,2
Maccabi,3,2,1
```

אם אחת העמודות חסרה, התוכנית תדפיס הודעה מתאימה ותדלג על הניתוח.

## שימוש

```python
from dashboard import analyze_football_data

analyze_football_data('football_data.csv')
```

## מה הפונקציה מבצעת

1. קוראת את קובץ ה-CSV ומדפיסה מידע כללי: כמות השורות, שמות העמודות ותצוגה של השורות הראשונות.
2. מסכמת את מספר השערים לכל קבוצה ומדפיסה את התוצאה.
3. מציגה גרף עמודות של שערים לפי קבוצה (ממוין מהנמוך לגבוה).
4. מדפיסה ממוצע בישולים לכל קבוצה וסך הכרטיסים הצהובים לכל קבוצה.

## הערות

- הגרף מוצג באמצעות `plt.show()`, ולכן נדרשת סביבה גרפית (או backend מתאים של matplotlib).
- כותרות הגרף בעברית — ייתכן שיידרש פונט התומך בעברית כדי שיוצגו כראוי.
